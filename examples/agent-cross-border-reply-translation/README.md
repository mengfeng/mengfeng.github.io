# 跨境客服翻译 Agent：锁定事实，生成待审阅草稿

Node.js 22+。所有源文、术语和政策为虚构内存夹具，`mockCandidate()` 是固定模拟模型响应。没有真实翻译模型、业务接口、退款或对外消息。

```bash
npm ci
npm run typecheck
npm test
npm run build
python3 -m http.server 8765
```

打开 `http://127.0.0.1:8765/`。切换七个场景并点击“读取证据并生成英文草稿”。订单号和金额先替换成占位符；核对通过后才恢复原值。“模拟源文更新”会清除旧结果；“人工已审阅译意”仅修改本地页面状态。没有发送接口。

`npm test` 只验证固定夹具下的结构性关口：占位符数量、金额原值、术语与政策来源、退款承诺、源文版本和超时。它不能判断译文语义是否忠实，也不能证明真实模型或生产客服流程可靠。生产系统应在服务端保护敏感字段，并由具备权限的人工审阅最终文字。
