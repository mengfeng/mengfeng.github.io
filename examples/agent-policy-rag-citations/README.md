# 带引用的客服政策问答 Agent

Vue 3 + TypeScript，纯本地可运行的最小检索 Agent。固定模拟模型先调用只读 `searchPolicies`，再从本轮结果选择片段 ID 与精确原文；答案由页面把这些原文组织成抽取式展示。没有真实模型、向量检索、数据库、HTTP 业务接口或后台服务，也没有任何业务写入。

## 直接运行

已构建的 `app.js` 包含 Vue 与全部公开演示数据。解压打开 `index.html` 即可，不需要模型密钥、CDN 或安装依赖。也可在解压目录运行：

```sh
python3 -m http.server 8092 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8092/>。这仍是静态文件预览，Agent 查询不会发送业务接口请求。JSON 全文链接会打开随包的政策文件；通过静态预览或 GitHub Pages 打开时，它是普通文档资源请求，并不是模型或检索 API。

## 政策与检索

`policies/returns.json`、`policies/shipping.json`、`policies/custom.json` 是本例专门编写的三份教学资料，共四个片段。它们不对应真实商家、法定规则或售后承诺。不要把本例时间、条件或运费说明用于真实业务。

每个片段带 `id`、`docId`、`title`、`version`、`section`、`text`、受控 `source` 路径与关键词。`src/policies.ts` 只按问题是否包含预设关键词评分，稳定排序后最多取三个片段；没有分词、语义理解、向量、重排或召回率保证。

- “普通商品怎么退货？”：返回申请时间与商品状态两个片段。
- “演示运费谁付？”：返回运费片段。
- “定制刻字商品怎么办？”：返回定制片段。
- “演示会员积分过期吗？”：无匹配，明确缺少依据，不调用选择模型，不生成承诺。

包含多个主题的问题可能因三片段上限遗漏重要条件；关键词命中也不等于已经理解适用范围。页面应继续让用户核对原文，真实系统还需独立检索和回答评测。

## 模拟模型与引用校验

`src/core.ts` 中 `mockSelect` 返回：

```json
{"selections":[{"chunkId":"shipping.fee","quote":"与工具结果完整原文完全相同的字符串"}]}
```

该片段是协议示意，实际 `quote` 必须与本轮工具结果中的 `text` 完全一致。`validateSelection` 按 `unknown` 校验：根对象只允许 selections、最多三条且非空、每条只允许 chunkId/quote、ID 必须来自本轮结果、完整原文精确相等、ID 不重复。模型不能额外指定标题、版本、链接或自由回答。

校验全部成功才一次性渲染答案。只要其中一条失败，整份答案拒绝，不留下半段看似有效的承诺。文档标题、版本与全文路径取自受控工具结果，未采用模型生成的元数据。

场景选择器提供不存在 ID、已存在但本轮未检索 ID、篡改原文、夹带自由回答四种失败夹具。点击引用 `[1]` 会打开对应 details、移动焦点并滚动到原文；全文 JSON 链接可检查三份源文件。引用不靠颜色单独传达。

**精确引用校验仅证明来源与字面一致。** 本例没有验证任意自由回答的语义蕴含，不保证召回完整、政策正确有效、适用于所有条件或真实客服决策正确。它刻意避免让模型直接写不可核对的承诺。

## 页面状态与竞争响应

`createAgent(search, select, publish)` 提供 ask、getState、dispose。状态为 idle/searching/selecting/answered/no-evidence/error；工具调用记录与本轮提交问题快照始终可见。新执行清空旧答案与上下文；成功、失败和组件卸载都检查操作序号，旧查询/模型返回不能覆盖当前页面。

输入框是待提交文字，点击按钮才创建新执行。选择另一个模型夹具后也需要再次提交。所有问题、政策与引用按普通文本节点渲染，不使用 v-html 或 innerHTML。

## 重建与测试

本例以 Node 24.22.1 验证；锁定 Vue 3.5.43、TypeScript 5.7.2、esbuild 0.28.2。重建安装依赖需要 npm 网络：

```sh
npm ci
npm run typecheck
npm test
npm run build
```
