# 商品展示排查 Agent：离线演示

这是 Vue 3 + TypeScript 的静态教学示例。商品、展示规则、模型候选回答和时间均为固定虚构数据；不会连接店铺、搜索索引、真实模型或外部消息服务，也不会执行上架、下架或改规则操作。

## 直接运行

ZIP 中包含已构建的 `app.js`。解压后进入目录：

```bash
python3 -m http.server 8100 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8100/`。不用 API key。

## 修改源码

使用 Node.js 22 或更新版本：

```bash
npm ci
npm run typecheck
npm test
npm run build
```

`npm ci` 首次安装可能需要访问 npm 注册表。`npm test` 对固定夹具执行 22 项断言，覆盖已上架、草稿、规则关闭、筛选不匹配、超时、记录缺失、版本冲突、过期证据、伪造引用与页面变化。测试不代表真实模型评测或生产验证。

## 文件

- `src/core.ts`：两项本地只读工具、固定模拟候选回答和证据核验。
- `src/app.ts`：Vue 3 交互，控制场景、分类筛选、版本变化与结果展示。
- `test.ts`：离线断言。
- `app.js`：可直接在静态服务器运行的构建产物。

真实接入时应由服务端先核实用户或运营人员对商品与店铺的访问权限，再查询目录、规则、索引和缓存；不能把浏览器里的演示类型或来源 ID 当成可信授权。
