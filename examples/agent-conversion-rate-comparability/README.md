# 结账转化率周报核对 · Vue 3 示例

解压后可直接打开 index.html。修改源码时，在源码目录执行：

```sh
npm ci
npm run typecheck
npm test
npm run build
python3 -m http.server 8765
```

随后打开 http://127.0.0.1:8765/ 。下拉菜单提供八个固定场景。选择“两周口径一致”可见 8.00% → 7.20%，差值 −0.80 个百分点。也可试用分母变化、结算中、零分母、零付款、快照缺失、差值错误或引用旧快照。

数据工具与 Agent 输出均使用本地虚构样本。页面独立核对统计口径、快照和差值，结果只显示在本地，真实分析平台、模型和周报发送均未接入。src/core.ts 定义计算和证据核对，src/app.ts 实现 Vue 界面，test.ts 验证边界。
