# 商品文案合并预览

双击 `index.html` 即可离线运行。商品、初始版本和 Agent 候选均为固定演示数据。应用只更新当前内存中的页面草稿。

使用 Node.js 22 或更高版本重建。

```sh
npm ci
npm run typecheck
npm test
npm run build
python3 -m http.server 8077
```

在浏览器打开 `http://127.0.0.1:8077/`。首次安装依赖需要网络或 npm 缓存。

默认合并保留人工标题，并加上 Agent 的卖点说明。切换到「双方给标题写了不同结果」，先决定标题取哪一版再应用。决定后手动修改当前标题，旧决定会失效。也可查看双方写成同样结果、清空角标、旧版本和候选字段无效等情况。
