# Agent 批量商品资料检查 · Vue 3 + TypeScript

这是可以脱网运行的教学示例：固定模拟 Agent 计划触发 `check_product` 只读工具，检查十件虚构商品的标题、图片说明和规格是否缺失。没有模型请求、真实商城数据、商品修改或持久化。

## 直接运行

解压源码 ZIP，双击 `index.html`。已包含打包的 `app.js` 和 Vue，不需要 API key、Node、CDN 或网络。也可以在本目录运行 `python3 -m http.server 8095`，访问 http://127.0.0.1:8095/ 。刷新清空所有运行结果。

## 修改 TypeScript

使用 Node.js 22 或更新版本（本次在 Node 24.22.1 验证）：

```sh
npm ci
npm run typecheck
npm test
npm run build
```

`npm ci` 需要网络下载锁定依赖；页面运行、测试及构建本身不调用模型或业务接口。依赖固定为 Vue 3.5.43、TypeScript 5.7.2、esbuild 0.28.2。`VUE-LICENSE.txt` 保留 Vue 授权声明。`src/core.ts` 是队列和固定规则，`src/app.ts` 使用 Vue `h` 渲染并通过 `shallowRef` 整体替换状态快照，`test.ts` 是离线断言。

## 按这些步骤检查

1. 保持“正常计划 + 两项首次执行失败”，点击开始。十件商品独立更新，运行中不超过 3，峰值 3。首次结果为规则通过 5、资料待补齐 3、执行失败 2，共调用 10 次。
2. P02 缺标题、P05 缺图片说明、P09 缺图片说明及规格。这些是成功取得的规则检查结果，不是可以靠重试修复的工具故障。
3. P03 首次模拟暂时不可用，P07 首次模拟延迟 1500 ms，在 700 ms 时请求中止。点击“只重试失败项”，只再次调用 P03/P07，其他八项结果和次数保留。完成后规则通过 7、资料待补齐 3，总调用 12 次。
4. 重置后选择“拒绝未授权工具计划”。工具名 `delete_product` 在计划入口被拒绝，调用数为 0。
5. 重置后选择“拒绝 P05 的伪造商品回执”。P05 结果携带错误商品 ID，被标记为需人工核查且不能重试；P03/P07 仍可以重试。
6. 重置后选择“P03 持续失败，观察重试上限”。首次失败后重试一次，P03 累计 2 次仍失败，页面显示已达上限；重试按钮禁用，P07 成功，总调用 12 次。离线测试另验证十项全部持续失败时总调用最多 20 次。
7. 检查过程中点击“停止并重置”。页面先等待在途工具结束，期间禁止开始新批次；结束后回到待开始。旧批次结果不能覆盖新状态。

“已处理”是当前已取得终态的条目数，不是成功率。重试两项时它从 10/10 回到 8/10，然后回升；规则通过、资料缺项和执行失败另行统计。

## 边界与机制

- 计划入口接受 `unknown`，先限制数组长度，再严格校验工具名、字段集合、1–10 个已知且不重复的 ID，并复制 ID 数组，防止调用方在排队期间修改计划。页面固定选择全部十项。
- 3 个 worker 从同一个游标取下一项。每项调用至多 2 次、每批最多 20 次；重复开始和重试不会创建第二轮并发调度。
- 业务缺项直接展示；仅超时和显式 `RetryableError` 可重试。格式错误、错误商品回执和未知异常需要人工核查。本例不实现真实服务的退避或重试分类。
- 工具调用请求通过 Object.freeze 冻结，回执绑定 `batchId`、`sourceVersion`、`productId`、`attempt`。由于本例是固定的本地规则，额外重新计算缺项并比较回执；这不代表可在前端验证真实模型的语义判断。
- 超时调用 `AbortController.abort()` 后仍等待工具 Promise 完成，才释放 worker。模拟工具会清理计时器、监听并 reject。仅 `Promise.race` 不会停止后台工作，因此这里没有用它抢先释放槽位。
- 如果替换的工具不理会 AbortSignal，它仍占据槽位直到结束；永不结束时会卡住，重置也会停留在等待中。这个示例优先保证不叠加新的执行，不能声称具备强制终止任意远端服务的能力。
- 重置递增 generation，防止旧结果/错误回写；在途任务没有全部结束前不允许新批次。批次 ID 是本页面内递增编号，刷新后重置，不能充当生产幂等键。
- 并发限制仅适用于单个控制器/页面，不是多标签页或多用户的全局限流，也不是服务端鉴权。真实接入需要后端持有队列、权限、租户隔离、超时、取消回执和持久化记录。

离线测试覆盖并发峰值、部分失败、只重试失败项、次数上限、计划/回执校验、稀疏数组、外部计划数组修改、重置/卸载过期响应以及不合作工具的等待边界。浏览器验收由博客集成流程单独记录，不把本文件当作公网发布证明。
