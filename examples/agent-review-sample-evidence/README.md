# 商品评价主题核对 · Vue 3 示例

解压后可直接打开 index.html。若要修改源码并重新构建，在解压目录执行以下命令，再打开 http://127.0.0.1:8765/。

```sh
npm ci
npm run typecheck
npm test
npm run build
python3 -m http.server 8765
```

用下拉菜单切换七个场景。默认场景的两个主题各有两条评价被引用。展开原文可以发现 R-02 同时出现在两个主题。同一主题重复引用只计一次。样本外编号或引文不符只剔除相应引用，旧快照、空样本或错误候选结构阻断整个结果。

评价读取与 Agent 建议均为本地固定样本。检查覆盖快照、编号、引文与去重。主题语义、实际采样覆盖、真实模型和生产权限需要另行验证。
