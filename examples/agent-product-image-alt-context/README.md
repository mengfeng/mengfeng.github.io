# 商品图片替代文本复核

直接打开 `index.html` 可离线体验。示例商品、布局配置和 Agent 候选都是固定样本，页面无需访问商品系统，也不会调用真实模型。

使用 Node.js 22 或更高版本，在当前目录运行。

```sh
npm ci
npm run typecheck
npm test
npm run build
python3 -m http.server 8077
```

打开 `http://127.0.0.1:8077/`。首次安装依赖需要 npm 缓存或网络。生成图片作为离线样本随包分发。

- `src/fixtures.ts` 定义页面位置、已确认的可见细节和模拟候选。
- `src/core.ts` 校验候选用途、位置、图片版本和引用，产出替代文本或复核结果。
- `src/app.ts` 在三种实际 HTML 上下文里预览结果。

默认详情图生成简短的内容替代文本。切到「图旁已完整描述」会看到显式空值，切到「独立图片链接」可用键盘激活链接。其余场景会阻断不适用的候选。
