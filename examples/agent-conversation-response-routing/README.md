# 客服会话结果归属 · Vue 3 示例

在解压后的目录运行以下命令。示例在 Node.js 18.12.1 环境中验收。

```sh
npm ci
npm run typecheck
npm test
npm run build
python3 -m http.server 8765
```

打开 http://127.0.0.1:8765/ 。源码包也带有构建好的 app.js，可以直接用浏览器打开 index.html。

1. 在客户 A 的配送会话启动任务 1，切到客户 B 的退货会话，在那儿启动任务 2。
2. 留在客户 B，投递任务 1，确认当前仍等待任务 2。投递任务 2 后可见 B 的草稿，再切回 A 查看独立保存的草稿。
3. 在同一会话连续启动两个任务，先投递后一项，再投递前一项。记录会显示前一项已被替代。
4. 试用归属不符、字段错误和工具失败。重置工作区后，尝试投递旧任务，检查草稿依旧为空。

所有会话、只读工具结果和候选文案来自本地固定样本。手动投递控制返回顺序，无需模型、服务器业务接口或外部网络请求。预构建页面只读取同目录的 JS 与 CSS。

`src/core.ts` 管理启动时的归属、结果校验与存放，`src/app.ts` 负责 Vue 界面与模拟队列，`test.ts` 验证关键结果分支。
