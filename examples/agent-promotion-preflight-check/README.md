# 促销活动预检 Agent：离线演示

Vue 3 + TypeScript 静态教学示例。活动、商品和优惠券均为固定虚构数据，候选回答由 `mockCandidate()` 固定生成；没有真实模型、商家接口、付款、消息或活动发布操作。

## 直接运行

ZIP 包含已构建的 `app.js`。解压并进入目录，执行：

```bash
python3 -m http.server 8100 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8100/`，无需模型密钥。

## 修改源码与验证

使用 Node.js 22 或更新版本：

```bash
npm ci
npm run typecheck
npm test
npm run build
```

首次 `npm ci` 可能需要访问 npm 注册表。`npm test` 对固定夹具运行 29 项离线断言，覆盖通过、时间窗错误、商品不适用、优惠券不可叠加与超时、版本冲突、过期或缺失证据、伪造引用和页面草稿变化。这些测试不证明真实模型表现或生产规则正确。

## 文件

- `src/core.ts`：三项本地只读工具、固定模拟候选和确定性证据核验。
- `src/app.ts`：Vue 页面状态与交互。
- `test.ts`：离线断言。
- `app.js`：静态服务器可运行的构建产物。

真实系统应由服务端核实操作者权限、活动版本、商品与优惠券归属和最终规则；前端演示来源 ID 不具备授权或审计效力。
