# 差评回复 Agent：证据引用与待审阅草稿

Node.js 22+。本项目所有评价、订单和政策均为虚构内存夹具，`mockCandidate()` 是固定模拟候选。没有真实模型、商家 API、付款、退款或对外发送。

```bash
npm ci
npm run typecheck
npm test
npm run build
python3 -m http.server 8765
```

打开 `http://127.0.0.1:8765/`。依次切换六个场景并点击“读取证据并生成草稿”。“模拟评价更新”会清除旧证据和回复；“人工已审阅”只修改本地页面状态。`npm test` 离线检查完整、订单缺失、政策超时、订单不匹配、评价版本变化、无依据退款承诺和伪造引用。离线测试通过不代表真实模型或真实业务系统已验证。

若未来接入真实模型，应在服务端保管凭据，独立校验它引用的来源与允许的事实；发送回复须另设人工确认和服务端鉴权。此演示没有发送入口。
