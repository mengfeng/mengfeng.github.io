# 商品无结果时的 Agent 筛选放宽示例

这是纯本地演示：虚构商品目录、固定的模拟模型建议、只读搜索函数。无真实模型 API、支付、订单写入或外部消息。

## 直接运行

解压源码 ZIP 后直接打开 `index.html`，或运行 `python3 -m http.server 8097 --bind 127.0.0.1`，再访问 http://127.0.0.1:8097/ 。构建好的 `app.js` 已包含 Vue 和模板编译器，不需要 CDN。

## 修改源码

需要 Node.js 22+。在解压目录运行：`npm ci`、`npm run typecheck`、`npm test`、`npm run build`。首次 `npm ci` 需要访问 npm 注册表；页面运行本身不需要网络。

## 手工验收

1. 点击“查询演示商品”：显示 0 件。保持“可接受”候选，生成建议并确认，出现蓝色耳机 A；确认前筛选不变。
2. 重置后选择“危险”候选：生成建议被拒绝，“必须有货”仍锁定，查询次数不增加。
3. 重置后选择“过期”候选：建议被拒绝。
4. 勾选超时并查询：显示超时，不能生成放宽建议，也不能被当作无结果。

测试覆盖上述逻辑。这个静态页面只模拟工具与模型边界；接入真实系统时，服务端仍须校验筛选参数、权限和库存来源。
