# 订单状态与物流时间线 Agent 演示

所有订单、物流事件和回答均为固定虚构数据。`readOrder()` 与 `readTracking()` 是本地只读 Promise；`mockCandidate()` 是固定模拟模型回答，不连接真实模型、订单系统或承运商，也不发送消息。

已构建静态页面：在本目录执行 `python3 -m http.server 8100 --bind 127.0.0.1`，打开 http://127.0.0.1:8100/ 。无需 API 密钥。

修改 TypeScript：Node.js 22+，执行 `npm ci && npm run typecheck && npm test && npm run build`。首次 `npm ci` 需要 npm 注册表；本次离线测试使用缓存。源码在 `src/`，构建产物是 `app.js`。

先点“查询并核对”，再切换物流超时、晚到轨迹、取消冲突、版本变化。可勾选伪造引用，或查询后点“模拟页面状态变化”。晚到轨迹按事件发生时间排列，不能把最后收到的事件当成最新发生的事件；订单取消时即使承运商显示签收，也不直接宣称签收。

Vue 许可见 `VUE-LICENSE.txt`。真实接入时须由服务端验证账户与订单归属、绑定的物流单号、权限、快照版本和时效；需要真实模型时由服务端控制工具调用与回答校验。
