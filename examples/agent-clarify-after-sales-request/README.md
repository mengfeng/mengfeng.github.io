# 售后入口澄清 Agent：Vue 3 + TypeScript 离线演示

模型响应、两个订单和售后政策全部是本地固定夹具。没有调用模型 API，没有真实账号、网络请求、售后申请、退款或对外通知。它演示的是应用如何约束模型决策，而不是自然语言理解效果。

## 体验

双击 `index.html`，或在解压目录运行 `python3 -m http.server 8000` 后访问 http://localhost:8000 。Vue 已打包在 `app.js`，离线页面没有 CDN 依赖，不需要密钥。

选择场景后点击“运行模拟 Agent”，再明确选择订单与问题类型。开始时两个槽位均为空，应用不会默认第一项。只有 `selectOrder` / `selectIssue` 能填入用户槽位；模型 ready 不能替用户选择。切换订单会清空旧问题、政策和入口，要求重新选择。

六个场景：多订单追问、模型给未知订单、模型给未知问题、模型跳过追问、政策查询失败与重试、HTML 追问文本。未知订单首步拒绝；未知问题在用户选订单后拒绝。提前 ready 在槽位不全时被应用拦截。工具失败在必要选择齐全后首次触发，点击“重试只读政策查询”恢复。其他异常恢复正常场景可重新开始。

政策入口只展开本地资料核对说明，不创建或保存业务申请。这里的政策为自编演示文本，不能作为真实商家规则或法律意见。

## 重建

需要 Node.js 22 或 24、npm。直接依赖固定为 Vue 3.5.43、TypeScript 5.7.2、esbuild 0.28.2。首次安装需访问公开 npm registry；构建后网页可离线打开。

```sh
npm ci --registry=https://registry.npmjs.org
npm run typecheck
npm test
npm run build
```

`src/core.ts` 包含纯状态函数、模拟模型决策及只读政策工具；`src/app.ts` 用 Vue h() 的字符串子节点显示追问和政策，不使用 innerHTML/v-html。200 毫秒本地等待只显示加载状态，不代表模型延迟或流式输出。

8 个核心测试覆盖先追问、槽位不足不调用、完整选择、切订单清空、未知选择、提前 ready、只读重试、HTML 字符串与工具边界。是否生成 HTML 元素/触发弹窗需实际浏览器核验，不能从字符串单测直接推导。

真实系统需要在服务端核验身份与订单归属、策略版本、参数及响应，并实现超时和次数上限；前端选择校验不能替代服务端授权。真实写操作不能套用本例的只读重试。
