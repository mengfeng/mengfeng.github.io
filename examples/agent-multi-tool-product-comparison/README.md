# 商品对比 Agent：Vue 3 + TypeScript 离线演示

这是固定模拟模型、虚构商品和本地只读工具的演示，不调用真实模型，不发送网络请求，不查询真实库存，没有购买、支付或库存预占。数据不代表市场价格或实际可售状态。

## 直接运行

双击 `index.html`，或在本目录执行 `python3 -m http.server 8000` 后访问 http://localhost:8000 。Vue 已打包在 app.js，不需要密钥或 CDN。

固定比较 bag-01 / bag-02 / bag-03 三件商品。两类工具分别是 get_product_specs 和 get_stock，每件各查一次，总计划六个任务。Promise.allSettled 等全部本地任务结束后，按原请求ID汇合，不按完成先后拼行。

六个场景：全部成功；bag-02规格失败；bag-03库存失败；bag-02库存返回0；模型为bag-03换入ghost-999；说明含HTML文本。某个字段失败会显示未知与原因，仍保留三行。未知ID任务在应用参数检查时被拦截，所以实际执行四次工具，原bag-03行保留且两个字段未知。0库存明确显示缺货，缺失库存不能用0代替。

模型的最终说明仅接受 productId / reason，事实字段只从已校验的工具结果组装。固定说明只复述已知值或缺失状态；本例没有验证真实模型是否会在自由文本里编造事实。HTML字符串经Vue h()文本子节点显示，不能只凭字符串单测认定DOM安全。

执行记录是所有任务结束后的汇总，并非实时进度或token流式输出。20/60毫秒本地等待仅用于模拟完成顺序不同，不是接口性能数据。没有实现真实超时、取消、重试或服务端账号授权。

## 重建与验证

需要 Node.js 22 或 24、npm。首次安装需从公开 registry 下载依赖。锁定 Vue 3.5.43、TypeScript 5.7.2、esbuild 0.28.2。

```sh
npm ci --registry=https://registry.npmjs.org
npm run typecheck
npm test
npm run build
```

9 个核心测试覆盖保留原始请求、两种部分失败、零库存、未知ID、HTML字符串、参数/规格/库存/说明结构边界。浏览器另外核验表格行数、局部滚动、HTML文本与手机排版。今天构建复用了已有公开依赖，不表示今天重新执行过 npm ci。

入口：src/core.ts 为工具、校验、聚合与模拟说明；src/app.ts 为Vue状态和语义表格；build.mjs 为构建和测试入口。Vue及依赖版权注释保留在app.js，许可证见VUE-LICENSE.txt。

真实系统应在服务端执行工具、账号权限与商品范围检查，并处理超时/取消/结果版本；库存查询只是某个时刻的快照，不能承诺后续下单仍有货。不要将只读演示当作真实模型或交易流程验收。
