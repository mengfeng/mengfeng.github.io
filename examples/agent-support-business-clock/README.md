# 工单响应计时

在浏览器打开 `index.html` 就能离线体验。工单、排班和 Agent 候选都是固定样本。页面不会联系客服平台或模型。

## 从源码运行

使用 Node.js 22 或以上版本，在这个目录运行。

```sh
npm ci
npm run typecheck
npm test
npm run build
python3 -m http.server 8077
```

打开 `http://127.0.0.1:8077/`。安装依赖需要 npm 缓存或网络。

- `src/fixtures.ts` 保存排班、工单快照和模拟候选。
- `src/core.ts` 裁剪并合并时段，计算分钟并核对候选。
- `src/app.ts` 依据计算结果展示计时状态和候选核验状态。

默认跨夜工单计入两段各 20 分钟。切换到午休档得到 25 分钟，重叠档仍为 40 分钟。可继续查看恰好到限、超时、覆盖不足、旧模型结果、错用自然分钟和完整覆盖下的零分钟。
